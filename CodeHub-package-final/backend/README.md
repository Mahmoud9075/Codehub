# Code Hub — الباك إند وقاعدة البيانات

الباك إند ده مبني بـ **Vercel Serverless Functions** (فولدر `api/`) + قاعدة بيانات **Supabase** (Postgres مجاني).
مهمته: تسجيل الطلاب، إظهار الشهور والكويزات، فتح كل كويز تلقائي بعد ما اللي قبله يخلص، وحفظ النتائج علشان تقدر تشوف اسم كل طالب ونتيجته.

## الخطوات

### 1) اعمل حساب Supabase (مجاني)
1. روح [supabase.com](https://supabase.com) واعمل حساب.
2. اعمل **New Project** واختار اسم وباسورد لقاعدة البيانات (احتفظ بيهم).
3. من داخل المشروع: **SQL Editor** → **New query** → الصق كل محتوى ملف `schema.sql` اللي معاك → دوس **Run**.
   - ده هيعمل الجداول (الطلاب، الشهور، الكويزات، النتائج) ويملأ 12 شهر و96 كويز (8 لكل شهر) تلقائي.
4. من **Project Settings → API** هتلاقي:
   - `Project URL` → ده هو `SUPABASE_URL`
   - `service_role` key (تحت API keys) → ده هو `SUPABASE_SERVICE_ROLE_KEY`
   - ⚠️ الـ service_role key ده سري جدًا، متحطوش في الفرونت إند أو تشاركه مع حد — بيتحط في السيرفر بس.

### 1.5) صور البروفايل (Supabase Storage)
عشان الطالب يقدر يضيف صورة شخصية:
1. من نفس مشروع Supabase: **Storage → Create a new bucket**.
2. سمّيه بالظبط: `avatars`
3. فعّل **Public bucket** (عشان الصور تظهر في الموقع من غير مشاكل صلاحيات).

### 2) جهّز الملفات
1. اعمل مشروع جديد فاضي وحط فيه فولدر `api/` وملف `package.json` زي ما هما.
2. من جوه المشروع شغّل:
   ```
   npm install
   ```

### 3) ارفع على Vercel
1. ادفع المشروع على GitHub (أو استخدم Vercel CLI مباشرة: `npx vercel`).
2. من [vercel.com](https://vercel.com) اعمل **Import Project** واختار الريبو.
3. قبل الـ Deploy، روح على **Environment Variables** وحط:
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `ADMIN_SECRET_KEY` (اختار أنت أي كلمة سر قوية، هتستخدمها إنت بس)
4. دوس **Deploy**.

### 4) اختبر إن كل حاجة شغالة
بعد الـ deploy هيديك رابط زي `https://your-project.vercel.app`. جرّب:

- **تسجيل حساب طالب جديد:**
  ```
  POST https://your-project.vercel.app/api/auth/register
  Body: { "first_name": "أحمد", "last_name": "محمد", "phone": "01012345678", "email": "ahmed@gmail.com", "password": "******" }
  ```
- **دخول الطالب:**
  ```
  POST https://your-project.vercel.app/api/auth/login
  Body: { "phone": "01012345678", "password": "******" }
  ```
- **نسيان الباسورد (خطوة 1: طلب كود)** ثم **استرجاع الباسورد (خطوة 2: الكود + باسورد جديد)**:
  ```
  POST https://your-project.vercel.app/api/auth/forgot-password    Body: { "phone": "..." }
  POST https://your-project.vercel.app/api/auth/reset-password     Body: { "phone": "...", "code": "123456", "new_password": "******" }
  ```
  ⚠️ **مهم**: الكود دلوقتي بيتسجل في قاعدة البيانات بس، مش بيتبعت SMS أو واتساب فعليًا للطالب —
  ده محتاج نربطه بخدمة زي Twilio أو WhatsApp Business API. لحد ما نعمل كده، تقدر تدخل تشوف الكود
  من جدول `password_resets` في Supabase وتديه للطالب لو اتصل بيك.
- **هات الشهور:**
  ```
  GET https://your-project.vercel.app/api/months
  ```
- **هات كويزات شهر معين لطالب معين** (لمعرفة إيه المفتوح وإيه المقفول):
  ```
  GET https://your-project.vercel.app/api/quizzes?month_id=...&student_id=...
  ```
- **تسجيل نتيجة كويز:**
  ```
  POST https://your-project.vercel.app/api/submit-result
  Body: { "student_id": "...", "quiz_id": "...", "score": 8, "total": 10 }
  ```
- **إنت بس: شوف كل الطلاب ونتايجهم** (المكان اللي كنت بتسأل عليه):
  ```
  GET https://your-project.vercel.app/api/admin/results?key=ADMIN_SECRET_KEY-بتاعك
  ```
  هيرجعلك قايمة فيها اسم كل طالب، رقمه، الشهر، اسم الكويز، والدرجة.

## إزاي الفتح التلقائي شغال؟
كل كويز ليه ترتيب (`order_index`) جوه شهره من 1 لـ 8. لما الطالب يسجّل نتيجة كويز رقم 3 مثلًا (`/api/submit-result`)،
أول ما تطلب `/api/quizzes` تاني هتلاقي كويز رقم 4 اتحول لـ `"status": "unlocked"` تلقائي، والباقي لسه `"locked"`.
مفيش أي حاجة يدوية — كله محسوب في السيرفر.

## لوحة التحكم (admin.html)

فيه ملف منفصل اسمه `admin.html` — ده لوحة التحكم بتاعتك. افتحه في المتصفح (مش لازم يكون على نفس دومين الموقع).

### تسجيل الدخول
- **إنت**: بتدخل برقم سري من 6 أرقام تختاره إنت (`ADMIN_PIN` في Environment Variables).
- **أي حد تاني**: بيدخل بحساب Google، بس لازم إيميله يكون مضاف من تبويب "الأدمن" جوه اللوحة الأول.

### إعداد الدخول بجوجل (اختياري — لو محتاج أدمن تاني غيرك)
1. روح [console.cloud.google.com](https://console.cloud.google.com) واعمل مشروع جديد.
2. من **APIs & Services → Credentials → Create Credentials → OAuth Client ID**.
3. النوع: **Web application**.
4. في **Authorized JavaScript origins** حط الرابط اللي هتفتح منه `admin.html` (مثلاً رابط GitHub Pages أو أي استضافة تحطه فيها).
5. هياخدك **Client ID** — حطه في:
   - `GOOGLE_CLIENT_ID` في Environment Variables بتاعة فيرسيل.
   - جوه ملف `admin.html` نفسه، في المتغير `GOOGLE_CLIENT_ID` أول السكريبت.

### قبل ما تشغّل اللوحة
1. في `admin.html`، غيّر المتغير `API_BASE` في أول السكريبت لرابط مشروعك على فيرسيل (نفسه اللي هتستخدمه في باقي الملفات).
2. في `CodeHub.html` (ملف الموقع الرئيسي)، هتلاقي قرب آخر الملف متغير اسمه `CH_API_BASE` — حطه بنفس رابط فيرسيل. ده اللي بيفعّل وضع الصيانة، إخفاء الأقسام، وتتبع الزوار.

### الأسئلة (📝 تبويب الأسئلة)
تقدر تختار شهر وكويز، وتضيف أسئلة اختيار من متعدد (سؤال + 4 اختيارات + تحديد الصح). دلوقتي الأسئلة بتتخزن،
بس الطالب لسه بياخد درجة عشوائية شكليًا في صفحة الموقع (المسار الشهري) — الخطوة الجاية إننا نربط شاشة الطالب فعليًا
بالأسئلة دي عشان يجاوب عليها بجد وتتحسب درجته الحقيقية. قولّي لما تحب نعمل الخطوة دي.

### الصيانة وإخفاء الأقسام (🛠️)
- زرار "إيقاف الموقع مؤقتًا" بيوقف الموقع كله ويظهر بدله رسالة "تحت الصيانة" لأي حد يفتحه.
- تقدر تخفي قسم بعينه (زي "المميزات" أو "آراء الطلاب") من غير ما توقف باقي الموقع.

### الزوار (📊)
بيوريك إجمالي عدد الزيارات، وعدد الزيارات لكل صفحة/قسم.

## المسار الشهري الجديد (8 شهور + اختبار نهائي)
- **8 شهور بس**: أكتوبر، نوفمبر، ديسمبر، يناير، فبراير، مارس، أبريل، مايو.
- كل شهر فيه **8 كويزات أسبوعية** (زي الأول) + **اختبار نهائي واحد** في آخره.
- الطالب لازم ياخد **70% في الاختبار النهائي** عشان الشهر اللي بعده يتفتح. لو أقل، الشهر اللي بعده يفضل مقفول ولازم يعيد.
- الشكل بقى **قايمة منسدلة (Accordion)** بدل الكروت — كل شهر ليه 🔒 (مقفول) أو 📖 (متاح) أو ✅ (خلّصته)، وتدوس عليه ينزل تحته الأسئلة.
- لو حطيت شهر جديد ولسه ما ضفتش أسئلة للاختبار النهائي بتاعه، الطالب هيشوف "لسه الاختبار منزلش" بدل ما يلاقي صفحة فاضية أو خطأ.
- **إضافة شهر جديد من غير كود**: من لوحة التحكم (زر جديد هيتضاف) بيولّدلك تلقائي 8 كويزات + اختبار نهائي للشهر الجديد.

⚠️ **ملحوظة مهمة**: نظام الأسئلة الحقيقية لسه محتاج يتربط بشاشة الطالب (زي ما اتكلمنا قبل كده) — دلوقتي شاشة الطالب لسه بتدّي درجات تجريبية عشوائية لغرض المعاينة، مش بتاخد من الأسئلة الحقيقية اللي بتضيفها من اللوحة.

## محتوى الموقع (تبويب "✏️ محتوى الموقع" في اللوحة)
تقدر تعدّل أهم نصوص الموقع (عناوين، أوصاف، الفوتر...) من غير ما تفتح كود خالص:
- **معاينة فورية**: بتشوف النص وهو شكله هيبقى إيه وانت لسه بتكتب.
- **رجوع لنسخة قديمة**: زرار "↩ رجوع لآخر نسخة" لو غلطت في تعديل.
- **مقسّم حسب القسم**: الهيرو، المميزات، الاشتراك، المسار الشهري، عن المنصة، التقييمات، الفوتر.

⚠️ **مهم**: دلوقتي في لوحة التحكم النصوص دي بتتحفظ في قاعدة البيانات، لكن الموقع نفسه (`CodeHub.html`) لسه بيعرض النصوص الثابتة المكتوبة جواه مباشرة — الخطوة الجاية إننا نخلي الموقع "يسحب" النصوص دي من الباك إند (`/api/content`) بدل ما تكون ثابتة، عشان أي تعديل تعمله من اللوحة يبان على طول في الموقع الحقيقي.

## تنبيهات واتساب تلقائية 📲
بعد ما الطالب يخلّص كويز، الموقع بيحاول يبعتله رسالة واتساب تلقائية تهنّئه وتقوله إن الكويز اللي بعده اتفتح.
⚠️ **مش شغالة فعليًا لسه** — محتاجة حساب WhatsApp Business (Meta Cloud API) موثّق:
1. اعمل حساب على [developers.facebook.com](https://developers.facebook.com) وفعّل WhatsApp Cloud API (مجاني للتجربة).
2. هتاخد `WHATSAPP_TOKEN` و `WHATSAPP_PHONE_ID`، حطهم في Environment Variables في فيرسيل.
3. Meta لازم توافق على "قالب رسالة" (Message Template) قبل ما تقدر تبعت رسائل تلقائية — ده شرط منهم مش من عندنا.
لحد ما تخلّص الإعداد ده، الموقع هيشتغل عادي بس من غير ما يبعت رسائل فعليًا.

## تحقق رقم الموبايل 📱
من صفحة "حسابي"، الطالب يقدر يدوس "تحقق من رقم الموبايل" فيتولّد كود 6 أرقام.
⚠️ نفس ملحوظة الأكواد التانية: الكود بيتسجل في جدول `phone_otps` بس، لسه مش بيتبعت SMS فعليًا — محتاج خدمة زي Twilio.

## لينك متابعة ولي الأمر 👨‍👩‍👦
كل طالب له لينك سري خاص بيه (من صفحة "حسابي" → "انسخ لينك متابعة ولي الأمر")، يقدر يبعته لأهله.
ولي الأمر يفتح اللينك ده (ملف `parent.html`) ويشوف اسم ابنه، عدد الكويزات اللي خلّصها، ومعدله العام — من غير أي حساب أو تسجيل دخول، ومن غير ما يشوف أي بيانات حساسة (مفيش إيميل ولا رقم موبايل ظاهر).
لازم تحط رابط فيرسيل بتاعك في أول ملف `parent.html` (متغير `API_BASE`) عشان يشتغل.

## المسار الشهري بقى حقيقي فعلاً ✅
مبقاش شكل تجريبي — دلوقتي:
- الطالب لازم **يسجّل دخول** الأول عشان يدخل المسار الشهري (هيظهرله زرار "تسجيل الدخول" لو مسجّلش).
- الشهور والكويزات بتيجي فعليًا من قاعدة البيانات، مش من الذاكرة.
- لما يدوس "ابدأ"، بيشوف **الأسئلة الحقيقية** اللي حطيتها من لوحة التحكم، ويجاوب عليها سؤال سؤال.
- **الدرجة بتتحسب في السيرفر نفسه** (مش في المتصفح) — عشان محدش يقدر يغش بتعديل الكود.
- بعد ما يخلّص، بيرجع تلقائي يشوف حالة المسار المحدّثة (الكويز اللي بعده اتفتح، أو الشهر الجديد لو نجح في الاختبار النهائي).

⚠️ **الشرط الوحيد**: لازم تكون حطيت أسئلة فعلية لكل كويز من لوحة التحكم (تبويب "📝 الأسئلة") — لو كويز لسه مفيهوش أسئلة، الطالب هيشوف "لسه الاختبار منزلش" بدل ما ياخد كويز فاضي.

⚠️ **لازم تحط رابط فيرسيل بتاعك في متغير `CH_API_BASE_MP`** جوه ملف `CodeHub.html` (قرب باقي المتغيرات المشابهة زي `CH_API_BASE` و`CH_API_BASE_STUDENT`) عشان الجزء ده يشتغل.

## المساعد الذكي (الشات) 🤖
دلوقتي الموقع فيه مساعد ذكي حقيقي شبه ChatGPT بالظبط:
- **بيجاوب من محتوى المنهج** اللي بتضيفه من لوحة التحكم (تبويب "✏️ محتوى الموقع" — قريبًا تبويب مخصص لقاعدة المعرفة).
- **لو السؤال برّه المنهج**، بيجاوب من معرفته العامة مباشرة وبوضوح (مش بيقول "معرفش").
- **سجل محادثات كامل** — الطالب يقدر يفتح ✏️ ويشوف كل محادثاته القديمة ويرجعلها.
- **رفع صورة** — الطالب يقدر يرفع صورة سؤال ويسأل عليها.
- **لوحة "أكتر الأسئلة"** في اللوحة (تبويب جديد) بتوريك أكتر حاجة الطلاب بيسألوا فيها، عشان تعرف تركّز شرحك فين.

⚠️ **عشان الجزء ده يشتغل، لازم تحط مفتاح Anthropic API في متغير البيئة `ANTHROPIC_API_KEY` في إعدادات فيرسيل:**
1. روح على [console.anthropic.com](https://console.anthropic.com) واعمل حساب (لو معندكش).
2. من صفحة API Keys، اعمل مفتاح جديد.
3. في فيرسيل: Settings → Environment Variables → ضيف `ANTHROPIC_API_KEY` بقيمة المفتاح.
4. ده خدمة مدفوعة حسب الاستخدام (مش مجانية بالكامل) — تقدر تحدد حد أقصى للإنفاق من نفس صفحة Anthropic.

بدون المفتاح ده، المساعد هيقول للطالب إنه "لسه مش متفعّل" بدل ما يعطي خطأ غريب.
